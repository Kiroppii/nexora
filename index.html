Abstract

This project is a web-based Barangay Management System designed to streamline daily barangay operations. It centralizes resident information, manages certificate requests, and supports administrative tasks such as approvals and record keeping. The system allows residents to submit requests digitally, while barangay staff can efficiently process, track, and manage these requests through an organized interface. Additional features include incident reporting, community event management, and secure user authentication. The goal is to improve efficiency, reduce manual workload, and provide a more reliable and transparent service for both barangay officials and residents.

System Workflow (BPMN)

This BPMN diagram shows the Barangay Document Request process in the One Barangay System with two actors: Resident and Barangay Admin. The process starts when the resident submits a request and uploads requirements. The barangay admin verifies the request, checks completeness, and decides to approve or reject. If approved, the admin prepares the document and notifies the resident for release. The process ends when the resident receives the document.
